# Resources

What the IDE loads at run time from its folder's `Resources`: the fonts its window draws with, Inter for the
interface and JetBrains Mono for code.

| Files | Are | From |
|---|---|---|
| `InterVariable.ttf` | Third-party | Inter 4.001 (variable), by Rasmus Andersson, rsms.me/inter, under the SIL Open Font License 1.1. |
| `JetBrainsMonoNL-Regular.ttf` | Third-party | JetBrains Mono NL 2.304, by JetBrains, jetbrains.com/lp/mono, under the SIL Open Font License 1.1. |
