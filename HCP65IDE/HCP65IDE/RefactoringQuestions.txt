 1. Rename and a template's family (T2).  A member a template's body names (mp->Init() in CHolder<M>) is now always

    method ("rename base method too?"); I didn't add a question here because "no" has no working outcome.  Is
    all-or-cancel right, or do you want a choice that leaves the template for you to fix?

    the native Release|x64 IDE instead, as earlier sessions ran them.  Do you want main made __cdecl there (as the
    test projects' mains are), so the checks can run with no window on Windows too?

    2026-11-13) and I left it; the suite was proved in Release|x64.  Should the test silence the logger around
    that line?

    header out of the files that have them.  Is that what you want, and should the files go to the recycle bin or

    you want it measured and, if it is cheap, turned on?

 6. A value parameter of a template as itself has no value, and is 1 where the check needs one: "M maItems[N]" is
